# 7. YÊU CẦU 2 — EXTEND: HIỂN THỊ SLOT ĐÃ BOOKED

Project đã có:

```tsx
const [bookings, setBookings] =
  useState<Booking[]>([]);
```

Dữ liệu này được cập nhật từ:

```text
Firestore
→ onSnapshot()
→ bookings state
```

Trong phần render từng slot, xác định slot đã được book hay chưa.

Gợi ý:

```tsx
const isBooked =
  bookings.some(
    (booking) =>
      booking.roomId
        === selectedRoom?.id
      &&
      booking.slot
        === slot
  );
```

---

# 8. HIỂN THỊ `Booked`

Nếu slot đã có booking:

```text
08:00-09:00 - Booked
```

Nếu chưa có:

```text
08:00-09:00
```

Ví dụ:

```tsx
<Text>
  {isBooked
    ? `${slot} - Booked`
    : slot}
</Text>
```

---

# 9. DISABLE SLOT ĐÃ BOOKED

Trong `Pressable`:

```tsx
disabled={isBooked}
```

Ví dụ:

```tsx
<Pressable
  disabled={isBooked}
  onPress={() =>
    setSelectedSlot(slot)
  }
>
  <Text>
    {isBooked
      ? `${slot} - Booked`
      : slot}
  </Text>
</Pressable>
```

```text
A201 / 08:00-09:00
```

đã có booking thì:

```text
08:00-09:00 - Booked
```

và không thể chọn slot đó.

# 19. GIẢI THÍCH WORKFLOW

```text

       ↓

       ↓
```
